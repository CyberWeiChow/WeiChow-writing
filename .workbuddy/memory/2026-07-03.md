# 2026-07-03 — 交互美化

## 阅读器版式差异化 + 交互优化

### 三种文章分类的差异化阅读版式 (build.py)
- **创意写作 (reader-variant-creative)**: Noto Serif SC, 18px, line-height 2.15, 双线分割线, 倾斜 lede, 宽松版式
- **文化批评 (reader-variant-criticism)**: Noto Serif SC, 16.5px, line-height 1.9, text-align justify, 较紧凑的学术风格
- **财经新闻 (reader-variant-news)**: Noto Sans SC, 16px, line-height 1.82, 粗体 byline (记者), lede 左侧边框, 更小的段落间距

### 移除功能
- 删除了文字躲鼠标交互 (charsToSpans, mouse dodge, cacheCharPositions)
- 摆脱了逐字 span 包裹的开销

### 新增功能
- 阅读时间预估 + 字数统计 (reader-meta-bar)
- 返回顶部按钮 (back-to-top)，滚动超过 400px 显示
- 字数计算基于 raw text（排除缩进全角空格）

## 高级感视觉升级（参考小红书视频）

参考视频呈现的是奶油色背景 + 大号衬线标题 + 编辑式留白的手绘线条分隔风格。为此做了以下调整：

### 色板
- 亮色：更暖的奶油背景 `#f5f2eb`、更柔和的墨水色 `#1f1c17`、强调色 `#8a7d6b`
- 暗色：偏暖的深色背景 `#0f0e0d`、柔和的墨水 `#ece7dd`、强调色 `#c4b49a`

### 字体
- 引入 `Cormorant Garamond` 作为英文展示衬线
- 首页姓名、分类页大标题、联系页标题使用衬线字体，增强编辑感

### 首页 Bio
- 姓名从 38px 放大到 56px，使用 Noto Serif SC + Cormorant Garamond
- 新增 tagline 展示（manifest.site.tagline）
- 各版块标题改为斜体衬线，留白更大

### 分类页
- 标题从 48px 放大到 72px，衬线字体
- 副标题改为英文斜体 tagline
- 增加波浪形 SVG 分隔线（cat-divider），呼应手绘线条审美
- 作品卡片略微增大、标题改用衬线，hover 时轻微去灰 + 放大

### 导航
- 品牌字重减轻，导航链接增加下划线展开动画
- 当前页面下划线常驻
