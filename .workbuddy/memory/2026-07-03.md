## 高优先阅读体验功能（三项）

### 1. 长文目录 (TOC)
- 自动检测章节标题：正则匹配 `一、` `二、` `第X章` `【...】` 等模式（长度 < 50 字符）
- 当检测到 3+ 标题时，在右侧固定显示目录（仅 ≥1280px 宽屏）
- 使用 IntersectionObserver 实现滚动追踪高亮（rootMargin: -100px 0px -70% 0px）
- 标题渲染为 `<h2 class="toc-heading">` 而非 `<p class="para">`，带 scroll-margin-top
- `initTOCTracking()` 在 `showRead()` 末尾调用，切换文章时 disconnect 旧 observer
- **Bug 修复 (2026-07-09)**: TOC 链接 `href="#sec-X"` 会触发 hashchange → route() → 落入 showBio()。修复：①initTOCTracking 中给链接加 click handler + preventDefault + smooth scroll；②route() 开头加守卫 `if (h !== '#' && !h.startsWith('#/')) return;`

### 2. 上一篇 / 下一篇导航
- 在同分类作品中查找当前文章索引，生成 prev/next 链接
- 文末两栏布局，带 "← Previous" / "Next →" 标签
- 无上一篇时左侧留空，无下一篇时右侧不显示

### 3. 相关推荐
- 文末展示同分类最多 3 篇其他作品卡片
- 卡片包含年份、标题、副标题（如有，单行截断）
- 带边框，hover 时边框变亮 + 背景微变
